> **BW1100 基线复测确认（2026-09-16，<device-alias>，8 卡全空闲）**：`install.sh + commit 66e513c + --gpu_targets gfx938` 在 DTK-26.04-rc4 容器（vllm:0.18.1-dtk26.04 镜像，**不挂宿主 /opt/dtk**）编译+运行通过，8 卡 all_reduce 峰值 busbw **131.71 GB/s**、alltoall 峰值 **127.05 GB/s**（2GB 消息），与上表基线 131.64/127.45 吻合。⚠️ 关键坑：容器**不能 `-v /opt/dtk:/opt/dtk`**——宿主 DTK-25.04.4 的 librccl 不含 gfx938 code object，会覆盖容器 DTK-26.04 导致 `invalid device function`（torch 也会 segfault）。

## 参考测试结果（BW1000 双机 16 卡）

| | algbw(GB/s) | busbw(GB/s) |
|---|---|---|
| all_reduce (DTK-25.04/25.04.1) | 62 | 117 |
| all_reduce (DTK-25.04.2) | 68 | 128 |
| alltoall (DTK-25.04/25.04.1) | 30 | 27 |
| alltoall (DTK-25.04.2) | 31 | 29 |

> 以此为基线，实测明显低于此值（如 busbw < 100 for all_reduce）即需排查 topo / 驱动 / 网卡配置。
