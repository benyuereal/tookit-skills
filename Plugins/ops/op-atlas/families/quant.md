# quant

量化与反量化。标度粒度（per-tensor / per-token / per-block）改变 kernel 结构，不可跨粒度比较。

## 本族判据

1. 先确认这段是否真的需要存在（很多访存原语的正确优化是「去掉它」）。
2. 字节数与访存模式比算法更重要。

## 实现横评

| 实现 | 层级 | 适合什么 | 不适合什么 | 证据 |

| `lightop` 融合族 | kernel | 需要融合 | 单条无链 | `libraries.md §3` |
| `in-house` | kernel | 特殊布局 | 常规形状 | 本仓实测 |
