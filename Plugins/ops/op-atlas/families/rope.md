# rope

位置编码旋转（RoPE 及其变体）。每层必经，档位简单但语义坑多。

## 本族判据

1. half vs interleaved：弄反**不报错，只是数值偏**，这是本族最贵的坑
2. 部分维度旋转：只转前 rot_dim 维，其余透传；写成全转不报错
3. 缩放变体：NTK / YaRN / linear，是参数不是新算子，但改变数值
4. 位置编码与 batch 内实际位置：变长 batch 下容易错位

## 实现横评

| 实现 | 层级 | 适合什么 | 不适合什么 | 证据 |
|---|---|---|---|---|
| `lightop` 融合族 | kernel | 需要融合残差/门控 | 单条无链算子（融合没有可省的往返） | `libraries.md §3` |
| `torch` 原生 | kernel | 基线对照 | 追求极限 | 本仓实测 |
| `TileLang` | kernel | 形状需要表达力 | 逼近手写极限（先付布局税） | `libraries.md §8` |
