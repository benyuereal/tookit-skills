# linear-attn

线性注意力与状态空间模型（Mamba2 / GLA / KDA / MHC）。串行 scan 与递推，优化手段是 tile 内移位不是 GEMM 那套。

## 本族判据

1. 先确认这段是否真的需要存在（很多访存原语的正确优化是「去掉它」）。
2. 字节数与访存模式比算法更重要。
