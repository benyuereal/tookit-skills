## 二、天花板算式（本卡是校准判据的最佳载体）

```
不融合残差：读 x + 读 w + 写 y = 2*M*H*2B
融合残差  ：读 x + 读 r + 读 w + 写 y = 3*M*H*2B

prefill-8k（M=8192, H=4096）不融合：2*8192*4096*2 = 134 MB
内存地板 = 134 MB / 1724 GB/s = 78 µs
```

**字节数完全确定、无中间态、无复用** ⇒ 达成率的分母没有争议。
这是全仓库最适合校准「带宽判据」的算子。

## 三、已确立的事实

| 事实 | 机制 | 影响 |
|---|---|---|
| 融合残差是唯一真收益 | 省一次 HBM 往返（3→2 或 4→3 次） | 不融合残差的变体上限就低一截 |
| `eps` 在 sqrt 内外数值不同 | `sqrt(mean+eps)` vs `sqrt(mean)+eps` | 小值输入下可见 |
| 原地写残差会污染多变体对比 | 后跑的吃到被改的输入 | 每个变体喂独立副本 |
| 用标称 1100 做分母会误判到顶 | 已有空间被算成 87% | 一律用实测 1724 |
