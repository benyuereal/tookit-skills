# perf — 模型级性能画像

存放**具体模型 + 具体镜像**的性能测量记录：吞吐、TTFT、TPOT、并发上限，
以及每条结论背后的**原始日志**（服务端日志片段、压测工具完整输出、官方账本 CSV 行）。

与 `data/`、`docs/` 的分工：

| 目录 | 放什么 |
|---|---|
| `perf/`（本目录） | **一次测量的完整证据**：口径、原始输出、结论、复现命令。带日期与镜像版本 |
| `data/` | 结构化数据（schema、db、issue-kb） |
| `docs/` | 方法论与规范 |

## 约定

1. **一篇文档 = 一次测量的完整证据链**，文件命名 `<模型>-perf-profile-<YYYYMMDD>.md`
2. **每节只贴一份完整原始数据**（不要贴多轮摘要），结论写在原始数据之后
3. **口径必须写清楚**：n、并发、输入长度、前缀命中率、是否预热、采样温度
4. **原始数据不可编辑**：工具的输出块要原样粘贴（含它自己的 `Median`/`P50` 标签）
5. 引用数字时标注「是否预热」——TTFT 均值对冷启动比例极敏感
